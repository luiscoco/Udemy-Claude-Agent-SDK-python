# Lesson 46: prompt caching and cost

This lab measures two turns in one native Claude Agent SDK session. Its owned loopback observer accepts only an authenticated fixed `/v1/messages` request with the current nonce and supported model, forwards at most two live requests to the fixed Anthropic endpoint, buffers bounded SSE and retains sanitized receipts. The host key never enters the child environment. Local mode uses actual authenticated HTTP with authored SSE responses and is labelled as a fixture.

The four actions are Anatomy (breakpoint locations), Switches (five-minute, one-hour or disabled caching), Breakers (stable, changed, tool, dynamic or short prefixes) and Model switch (a zero-dollar rewrite cap or an allowed switch). One selection is measured per click. The 180-section handbook includes a fresh operation UUID to limit accidental reuse from earlier runs; both turn prompts share a nonce. A short handbook does not prove the complete native CLI request is below the cache threshold. The 1-hour live variant is an owned wire perturbation of native breakpoints because this Python SDK version has no public prompt-cache-TTL option. Changed and tool variants are likewise labelled owned wire perturbations. They do not claim native mid-session system reconfiguration.

The wire inspector reports breakpoint locations and TTL but stores no prompt body. The complete SSE parser requires one start, at least one delta and a stop, with finite primary counters. It separates five-minute writes from one-hour writes, and never treats missing primary counters as zero. The dated 19 October 2026 list estimate applies Haiku 4.5 input/output rates of $1/$5 per million and Sonnet 4.5 rates of $3/$15, with write multipliers 1.25 or 2 and read multiplier 0.1. It is kept separate from the SDK session's cumulative cost. The evaluator requires both native results to succeed in one session, matches each assistant ID to the upstream message ID, compares independently reported SDK and wire counters, and checks finite nondecreasing cumulative cost. A complete zero-read measurement can pass.

For a model switch, the Python SDK's `sonnet` alias resolves to the pinned Sonnet 4.5 target in the native pre-hook. The capped case observed a warm cache and a positive rewrite estimate, denied the switch, had no post-hook and ran turn two on Haiku. The allowed case observed pre and post hooks, then a Sonnet 4.5 second-turn wire receipt with its actual usage. The hook estimate is a decision input, not the actual post-switch cost.
