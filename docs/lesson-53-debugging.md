# Lesson 53 debugging lab

The lab diagnoses one bounded Agent SDK run at a time. Seven fixed prepared scenarios cover success, denied Read, missing fixture, maximum turns, startup failure, API error and truncated debug log. The prepared path uses authored trace events and an owned fixture; it makes zero model calls. Four scenarios also support a separately consented native Haiku run: success, denial, missing fixture and maximum turns.

`/api/c53/facts`, `/code`, `/run`, `/runs/{id}`, `/active` and `/stop` expose strict inputs and an SSE timeline. Invalid input returns 400, an unapproved live request 403, a missing retained run 404 and an overlapping mutation 409. Each accepted run owns an exclusive fixture containing its UUID, an independent fixture hash, a maximum of five turns, a $0.10 SDK query cap and a 60-second deadline. The native tool policy admits only the exact owned Read through both a pre-use hook and permission callback. No retries are configured.

Trace rows correlate SDK messages, tool calls and results, hook decisions, stderr and terminals. Terminal evidence and a later iterator exception are both retained. Collection is bounded to 300 normal rows, 350 with forced cleanup, 500,000 serialized bytes and 128,000 debug-log bytes. The log descriptor closes on every path. Findings point to the first supported cause before downstream symptoms. The comparison accepts only one effective-field change between saved runs of the same provenance. Redacted bundles are saved atomically under `.lab-data/lesson-53/` and reloaded with their SHA-256 digest for the acceptance check.

Run `.venv/Scripts/python.exe scripts/debugging_check.py` for the free seven-scenario matrix. Add `--live --budget 1` for the four explicitly paid native scenarios. The browser presents the trace timeline, source and call filters, first-cause navigation, Stop, saved-run recovery and a redacted download. The Learning Guide includes seven explained questions, two diagrams and three source excerpts. See [live acceptance](live-acceptance.md) and [narration](lesson-53-narration.md) for observed evidence.
