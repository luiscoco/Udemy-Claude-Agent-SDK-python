# Lesson 48: security hardening

The lab compares four fixed probe sets across contrast and guarded lanes. Each lane has fresh synthetic `.env`, diagnostic, ticket, outside secret, outside marker target, child configuration, and a loopback collector. The host admits only known literal tool inputs. A local action performs real file or Python child-process effects; its SDK-like IDs are explicitly labelled authored host records. The live producer uses native SDK tools and hooks in a child process plus a host-owned model observer that holds the real upstream key. No real secret is placed in the owned fixtures.

Permissions probes the protected `.env` read, outside read and exact outside write. Lockdown probes child environment and owned egress. Secrets reads a diagnostic containing a known synthetic marker and tests output rewriting. Injection reads an untrusted ticket, then attempts the same protected read and egress; the ticket cannot grant tool authority. Each lane first receives an independent collector baseline receipt. The host checks call/result identity, tool admission, actual outside bytes, marker creation, collector bodies by digest and known-marker flag, and fresh TCP listener closure. The live observer additionally joins upstream message IDs and tool-result IDs and checks model-bound bytes for known marker forms.

Only exact registered synthetic marker values are rewritten by `PostToolUse`. The checker also scans their base64 and URL-encoded forms in relevant observed bytes, so an encoded marker can fail the experiment, but the rewriter does not claim to remove every encoding. Unknown secrets, arbitrary shell commands and arbitrary files are outside the fixed experiment. The SDK budget is $0.10 per lane and $0.20 per action; cost fields are SDK observations rather than an invoice.

The `/api/c48` routes strictly validate input, require enabled live access and fresh consent, serialize actions and reject unsafe saved summaries. Negative local scenarios remove evidence, substitute a result ID, set failure or mark a collector leak; they cannot update latest passing state.
