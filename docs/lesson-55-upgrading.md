# Lesson 55 offline SDK upgrade workshop

This lesson rehearses release decisions against nine fixed synthetic candidates. It reads the actual Python project's exact `claude-agent-sdk` pin, `uv.lock`, installed package metadata and three callable public exports. It hashes the manifest and lock bytes before and after every run. The workshop does not install an SDK, start Claude, make a network request or deploy code.

Each candidate passes through four independent gates: required exports, correlated application-adapter stream records, a simulated permission decision that denies an outside Write, and synthetic quality/cost/latency thresholds. The compatible fixture passes all four. Each other fixture changes a specific contract and is blocked by observed failing evidence. Unknown additive stream events are counted but cannot replace an init, matching Read return, completed task notification or successful terminal result. Synthetic metrics are authored classroom values, not model evaluations or billing.

`/api/c55/facts` inspects the environment; `/code` shows three source excerpts; `/run` assesses only a named fixed candidate; `/transition` recomputes eligibility and enforces checked → canary → promoted with rollback from canary or promoted. These states are stateless teaching inputs, not proof of a prior real deployment. The page labels the exercise **Offline simulation · no model calls**, resets evidence on edits or Stop, and shows gate observations and recovery. `scripts/upgrading_check.py` accepts no arguments, rejects `--live`, guards network and child-process entry points, assesses all nine fixtures, checks the transition sequence and unchanged hashes, then writes a sanitized ignored report.

For a real upgrade, retain a known-good artifact, manifest and lock, configuration, evaluation baseline and data snapshots. Review an exact candidate in an isolated checkout; read the [Agent SDK Python changelog](https://github.com/anthropics/claude-agent-sdk-python/blob/main/CHANGELOG.md) and [releases](https://github.com/anthropics/claude-agent-sdk-python/releases), then run a clean locked install, typecheck, offline suite and build. Test the candidate's actual MCP tools, hooks, denied actions, streaming, cancellation and resume behavior. Repeat comparable real evaluations, set measured canary stop thresholds, review promotion and test recovery of snapshots under a retained older runtime. The official changelog records changes to `system_prompt` and explicit `setting_sources`; choose both deliberately where isolation matters. Pins reproduce dependency bytes, not remote model behavior.

The Learning Guide has seven explained questions, two separate diagrams and three source-bound Yash clips. The final uninterrupted full offline regression passed 2,024 tests with 19 expected skips, and the offline wheel build passed. Human listening, Linux/WSL verification and independent student acceptance remain open.
