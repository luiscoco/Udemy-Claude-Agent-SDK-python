# Lesson 47: multi-agent orchestration

The Python lab uses the fixed north, south and east sales rows in `agent_lab/orchestra_lab.py`. Each run creates owned CSV files, retains their original SHA-256 values and checks the files again after work. Truth is north 55/P2, south 69/P1 and east 86/P2. No browser input can name a path, model, prompt, command or credential.

Five actions compare two scheduling sources. Orchestrator and hierarchy use actual native SDK Agent delegation: lead to analyst, or lead to manager to analyst. Pipeline, fan-out and evaluator use separate SDK queries scheduled by the host. A host-controlled dependency depth is not native subagent depth. Local mode authors worker lifecycle rows while performing owned file reads; it makes no provider call and does not certify native delegation.

The host matcher requires unique start/end identities, role, parent, depth and owner; one report and independent passing verdict per worker; an unchanged owned file and matching Read observation for each file owner; digest-bound pipeline/evaluator handoffs; and a released fan-out limiter. Native trees additionally join Agent tool use, admitted pre-hook, SubagentStart agent ID, task_started ID/depth, SubagentStop report and completed task notification. A parent answer cannot replace any child row. The analyst's first stop is blocked unless the whole output is the exact north report line. A second active stop passes through to avoid a loop, but the independent checker can still reject its values. The checker finds one anchored report line and compares fixture truth; it does not judge every possible interpretation of surrounding prose.

The fair host limiter queues at the selected limit of 1 or 2 and transfers a reserved slot directly to the first waiter in `release`. A failing or cancelled worker still releases its slot. The limiter controls host query concurrency, not native child concurrency or a shared monetary budget. Native query ceilings are $0.20 for orchestrator, $0.25 for hierarchy and $0.05 per host-controlled query, totaling $0.85 across the five-action matrix. SDK cost fields are estimates, not a reconciled invoice.

The strict API offers `GET /api/c47/facts`, `/state`, `/code`, `/source` and `POST /api/c47/{orchestrator,hierarchy,pipeline,fanout,evaluator}`. Invalid fields or choices return 400; live mode needs enabled access, normal scenario and fresh consent or returns 403. Concurrent actions and state inspection while active return 409. Only a passing bounded summary is saved, and reload rejects a symlink, non-regular, linked or oversized file. The shared lesson runner and browser use the same host handlers.
